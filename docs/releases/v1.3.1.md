# WhalePet v1.3.1

跨平台客户端 0.3.1 的发布版：**第一次把编译产物（Android 安装包 + Windows 便携包）直接放进仓库**，另外带若干小修。

## 下载

| 文件 | 说明 |
|---|---|
| `whalepet-android-0.3.1.apk` | Android 通用包（48.9 MB），含 arm64-v8a / armeabi-v7a / x86_64 |
| `whalepet-windows-x64-0.3.1+2.zip` | Windows 10/11 x64 便携包（15.5 MB），解压即用，含 VC 运行库 |
| `SHA256SUMS.txt` | 校验和（两个包都在里面） |

- Android：包名 `com.dywu.whalepet`，versionName `0.3.1`，versionCode `2`，
  minSdk 24（Android 7.0）/ targetSdk 36，签名 debug keystore（自用包，不是上架包）
- Windows：客户端版本 `0.3.1+2`，Release 构建，免安装、非管理员即可运行

Android 安装：

```bash
adb install -r whalepet-android-0.3.1.apk
# 或拷贝到手机点开安装（需允许安装未知来源应用）
```

Windows 运行：**整个目录一起解压**，双击 `whalepet_flutter.exe`（别只拿 exe，
它依赖同目录的 `flutter_windows.dll`、`data/` 和几个运行库 DLL）。首次启动后
右键宠物 →「设置」，填服务器地址与访问令牌。

## Android 端能力（阶段 C 第 1~2 步）

- **全屏海底场景**：立绘按状态做程序化动作（漂浮/摇摆/弹跳/挤压）、可拖动、点一下摸头
- **互动**：投喂 / 玩耍 / 睡觉 / 聊天面板 / 设置，数值与存档都在本地（15 秒自动存）
- **语音**：系统语音识别（`SpeechRecognizer`）收指令 → 带唤醒词时用 `WakeMatcher` 本地匹配 → 走 `/api/agent` 文本通道 → 系统 TTS 播报（播完才恢复采集，不会被自己的声音唤醒）
- **设置**：服务器地址 + 访问令牌（令牌用 Android Keystore 的 AES-GCM 加密后落盘）
- 与 Windows / macOS 桌宠共用同一份 `lib/core/`：状态机、数值、台词、协议、语音协调器完全一致

## Windows 端能力（阶段 E）

- **透明置顶桌宠**：380×560 无边框窗口，`WS_EX_LAYERED + WS_EX_TOOLWINDOW`，不进任务栏；
  透明区域自动穿透、不挡后面软件的点击；单击摸头 / 双击聊天 / 右键菜单 / 按住拖动。
  窗口能力全部走 `dart:ffi` 直连 user32，**零第三方插件**。
- **全离线语音闭环**：待机只跑 SAPI5 中文桌面识别器（`MS-2052-80-DESK`）的唤醒词小语法，
  说「小鲸小鲸」→ 播「我在」→ 切听写语法 → 识别成文本上行；播报期间自动闭麦。
  没有麦克风也能用 `WHALEPET_VOICE_WAV=<wav>` 注入音频跑通全链路。
- **播报**：`System.Speech` + 系统中文音色（本机验证音色 `Microsoft Huihui Desktop`）。
- **数据**：`%APPDATA%\WhalePet\`，设置明文、令牌 DPAPI 加密、宠物存档原子写。
- 与 Android / macOS 共用 `lib/core/`（协议 v2、语音协调器 8 态状态机、`SpeechQueue`）。

## 本版改动

- `chore(release)`：把编译产物收进仓库 —— `release/whalepet-android-0.3.1.apk`、
  `release/whalepet-windows-x64-0.3.1+2.zip`，附 `SHA256SUMS.txt`
- `fix(windows)`：便携包带上 VC 运行库。`flutter build` 的 Release 目录只有
  exe / `flutter_windows.dll` / `data/`，而主程序导入表点名 `MSVCP140.dll`、
  `VCRUNTIME140.dll`，干净 Windows 上双击会报「找不到 VCRUNTIME140.dll」。
  现在按 app-local 方式附带 `vcruntime140.dll` / `vcruntime140_1.dll` / `msvcp140.dll`
  / `d3dcompiler_47.dll`，缺必需项时打包脚本直接失败，不再产出残包
- `fix(android-tool)`：构建脚本同步到本地后清掉 macOS 的 `._*` / `.DS_Store`（这类 AppleDouble 文件被 `.gitignore` 忽略、不会进库，但名字匹配 `*.dart` 时会让 `flutter test` 在 UTF-8 解码上直接崩）
- `fix(windows)`：语音状态机三处 generation / 去重 / 重建缺陷（详见
  `docs/CROSS_PLATFORM.md` §17.4），以及待唤醒阶段把 SAPI 拒识当错误的自我重启循环
- `docs`：README 里 Android 产物名不再写死版本号

## 已知限制

- Windows 唤醒依赖系统自带的 **SAPI5 中文识别器**（`MS-2052-80-DESK / zh-CN`）；
  缺这个语言包（例如英文版 Windows 未装中文语音）时语音唤醒会报「未找到中文识别器」，
  文字聊天与 TTS 仍可用
- 唤醒是「连续系统识别 + 唤醒词文本匹配」的过渡方案（Android 默认关闭），耗电与延迟都不如真正的 KWS
- 本地 KWS/ASR 模型（sherpa-onnx）尚未接入——`VoiceEngineAdapter` 已留好替换位，换实现时协调器与 UI 不用动
- 一句话带命令（“小鲸小鲸，帮我查一下…”）还没做，目前是「唤醒 → 应答 → 再说指令」
- 仅供局域网/ZeroTier 使用：桥接服务器是明文 HTTP + Bearer，**不要暴露公网**
