## Android 端能力（阶段 C 第 1~2 步）

- **全屏海底场景**：立绘按状态做程序化动作（漂浮/摇摆/弹跳/挤压）、可拖动、点一下摸头
- **互动**：投喂 / 玩耍 / 睡觉 / 聊天面板 / 设置，数值与存档都在本地（15 秒自动存）
- **语音**：系统语音识别（`SpeechRecognizer`）收指令 → 带唤醒词时用 `WakeMatcher` 本地匹配 → 走 `/api/agent` 文本通道 → 系统 TTS 播报（播完才恢复采集，不会被自己的声音唤醒）
- **设置**：服务器地址 + 访问令牌（令牌用 Android Keystore 的 AES-GCM 加密后落盘）
- 与 Windows / macOS 桌宠共用同一份 `lib/core/`：状态机、数值、台词、协议、语音协调器完全一致

## 本版改动

- `chore(release)`：把编译产物 `release/whalepet-android-0.3.1.apk` 收进仓库，附 SHA256
- `fix(android-tool)`：构建脚本同步到本地后清掉 macOS 的 `._*` / `.DS_Store`（这类 AppleDouble 文件被 `.gitignore` 忽略、不会进库，但名字匹配 `*.dart` 时会让 `flutter test` 在 UTF-8 解码上直接崩）
- `docs`：README 里 Android 产物名不再写死版本号

## 已知限制

- 唤醒是「连续系统识别 + 唤醒词文本匹配」的过渡方案（默认关闭），耗电与延迟都不如真正的 KWS
- 本地 KWS/ASR 模型（sherpa-onnx）尚未接入——`VoiceEngineAdapter` 已留好替换位，换实现时协调器与 UI 不用动
- 一句话带命令（“小鲸小鲸，帮我查一下…”）还没做，目前是「唤醒 → 应答 → 再说指令」
- 仅供局域网/ZeroTier 使用：桥接服务器是明文 HTTP + Bearer，**不要暴露公网**
